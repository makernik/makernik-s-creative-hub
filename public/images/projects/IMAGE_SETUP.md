# Project Images Setup

## Required Images

The following images need to be added to this directory:

1. `smart-home-dashboard.jpg` - Smart Home Dashboard project
2. `mechanical-keyboard.jpg` - Mechanical Keyboard project
3. `generative-art-engine.jpg` - Generative Art Engine project
4. `led-matrix-display.jpg` - LED Matrix Display project
5. `portfolio-generator.jpg` - Portfolio Generator project
6. `modular-synth-module.jpg` - Modular Synth Module project

## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 800x600px (4:3 aspect ratio)
- **Max File Size**: 500KB per image (optimized for web)
- **Naming**: Use kebab-case matching the project slug

## Temporary Fallback

Until images are added, the site will show broken image placeholders. Consider:
1. Downloading images from the original Unsplash URLs
2. Using placeholder services (e.g., placeholder.svg) temporarily
3. Creating custom project images

## Image Optimization

Before adding images:
1. Compress images using tools like TinyPNG or ImageOptim
2. Consider WebP format for better compression
3. Generate responsive image sizes if needed
