# Images Directory

This directory contains all image assets for the website.

## Structure

- `projects/` - Project images and screenshots
- `about/` - About section images
- `og/` - Open Graph images for social sharing
- `icons/` - Icon files (if needed)

## Usage

Images should be referenced from the root:
- `/images/projects/project-name.jpg`
- `/images/about/profile.jpg`
- `/images/og/default.png`
