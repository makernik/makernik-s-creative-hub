# Homepage

Mode: Persuade.

Audience: anyone who lands on hello.makernik.com. Job: try MazeMaker. Proof: a maze drawn on the page, and only the projects, copy, and contact methods already in the repo. Constraints: static GitHub Pages build, cream / charcoal / copper, Space Grotesk and Inter, no invented apps, no blog, no resume.

## Direction contract

THESIS: The homepage is one paper map whose terrain is a maze, so the offer is the thing itself. It refuses the centered portfolio hero and the equal card grid.

OWN-WORLD: Cream sheet, charcoal ink, copper as the only spot color. A graph-paper graticule under the maze. The title sits in a cartouche on the sheet. A crowded legend holds the facts. Below the fold, build-log rows, bin labels, and empty photo mounts. Space Grotesk for titles, Inter for text.

STORY: The visitor reads MazeMaker, sees a maze draw itself, and uses Make a maze to open the live app. The same sheet continues into other apps, physical-build mounts, the maker story, and email.

FIRST VIEWPORT: Margin index across the top (wordmark, Apps, Builds, About, Contact, and Make a maze). The maze field fills the rest of the viewport. Cartouche top-left on that field, poster-scale: MazeMaker, the line “Make and Print mazes at home!”, and the primary Make a maze control. Legend band along the bottom: the README sentence, a code link, and Draw another. Signature interaction: the ghost grid is already there, then the walls draw once from the entrance and rest.

FORM: Folded trail map, fifth on the resonance list (activity sheet, workshop log, print docket, field notebook, trail map, catalog drawer, recipe card). Seed key 6a3c6d0d. Brief-pinned cream, charcoal, copper, Space Grotesk, and Inter replace map-green and a cartographic serif. Raises: poster scale (Emigre), quiet field against a crowded legend (obi), one draw then rest (chromatophore), paper and spot copper (riso), ghost grid before the walls (seven-segment).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
