# makernik.com

Personal creative portfolio showcasing digital and physical maker projects.

## Featured Projects

- **MazeMaker** — Make and Print mazes at home! Live at https://maze.makernik.com
- **Hidelog** — A personal log. Live at https://hidelog.lovable.app

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
